# Shruti Negi — Portfolio Website

A responsive personal portfolio website built with HTML, CSS and vanilla JavaScript.

## Preview locally
1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html` or open it with Live Server in VS Code.

No build tools or package installation are required.

## Files
- `index.html` — website content and sections
- `style.css` — responsive styling and layout
- `script.js` — mobile navigation, scroll progress and reveal effects
- `assets/profile.jpg` — profile portrait

## Publish with GitHub Pages
1. Create a GitHub repository named `portfolio` (or any name you prefer).
2. Upload all files and the `assets` folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. GitHub will provide your live website URL after deployment.

## Personalise before publishing
Update the About, Skills and Projects sections in `index.html` with your latest details. Add your real email or other contact links when you are ready.
